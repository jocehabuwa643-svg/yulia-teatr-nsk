# DATA_SOURCES.md — источники данных, статусы, как обновлять

Правило проекта: **ни одной цифры без источника, даты проверки и confidence.** Значение с
`status:"no_data"` показывается в интерфейсе как «нет данных» + кнопка ручного ввода; график не
подделывается никогда. Провенанс лежит рядом с каждым значением в `data/*.json`
(`value, unit, source_name, source_url, fetched_at, valid_from, valid_to, confidence, note`).

## Сводка статусов

| Источник | Что даёт | Статус | Куда пишется |
|---|---|---|---|
| Банк России (XML_daily / XML_dynamic) | курсы USD/EUR | **подключён** (`scripts/fetch-cbr.mjs`, cron Actions) | `data/rates.json → cbr` |
| Банк России (ключевая ставка) | ставка ЦБ | **нет публичного XML-эндпоинта** → ручной ввод | `cbr.key_rate` |
| НК РФ / ФНС / 228-ФЗ / приказы МЭР | налоги, пороги, взносы, НДС | **ручная проверка по ссылкам** (сверено 2026-11-19) | `rates.json → tax` |
| Закон НСО № 142-ОЗ | региональные УСН-льготы | **ручная** (текст — сканы; 2027 не опубликован) | `tax.usn_nso_social_*` по годам |
| Калькулятор патента ФНС | потенциальный доход НСО | **ручной ввод** (в справке есть ориентир 1 275 700 ₽, не проверен) | `tax.patent_potential_nsk` |
| ПФКИ / ФПГ / Минрегион НСО | гранты, окна подачи | **ручная** (сверено 18–19.11.2026) | `market.json → grants` |
| Исследование рынка (срез 18.11.2026) | конкуренты, цены, учреждения, ДК | **ручной срез** + полный архив | `competitors.json`, `data/archive.html` |
| Бизнес-модель проекта | аренда 1 000 ₽/м², билет 300–350 ₽, 70/30, гонорары, стадии | **предположения проекта** (`confidence:"model"`, редактируются в UI) | `config.json` |
| Яндекс Wordstat | спрос по запросам | **требует токена** (`WORDSTAT_TOKEN` в GitHub Secrets) | `market.json → demand` |
| 2ГИС / Яндекс Карты | геоданные площадок | **не используются API** (лицензии); координаты из исследования | `regions.json` |

## Автоматическое обновление

- `scripts/fetch-cbr.mjs` — курсы из ЦБ (без ключей). При недоступности источника прежние
  значения сохраняются и помечаются `stale:true` — сайт продолжает работать.
- Workflow `.github/workflows/data-refresh.yml` — cron 03:17 UTC ежедневно + кнопка
  `workflow_dispatch`; коммитит изменения в `data/`, обновляет `meta.generated_at`.
- Пороги устаревания (бейдж «Данные устарели, проверьте»): ставки — 7 дней, цены — 30,
  гранты — 30 (`rates.thresholds_days`, дублируются в `config.ui`).

## Обязательные ручные проверки (график)

| Что | Когда проверять | Где |
|---|---|---|
| Порог НДС УСН на 2027/2028 | до 01.01.2027 | `tax.vat_threshold.years` (сейчас 20 млн по 228-ФЗ) |
| Дефляторы и банды 250/450 млн | ноябрь каждого года | `vat_band_*`, `usn_deflator` |
| Льготы УСН НСО на 2027 | после публикации перечня | `usn_nso_social_*.years.2027` (сейчас no_data) |
| Фиксированные взносы ИП | после правок ст. 430 | `ip_fixed_contributions.years` |
| МРОТ 2027 | после принятия закона (сейчас законопроект 619-9) | `mrot.years.2027` |
| Окна ПФКИ/ФПГ/СОНКО | ежемесячно | `market.grants.programs` |
| Цены конкурентов | раз в месяц | `competitors.json` |

## Как получить токен Wordstat

1. Кабинет Яндекс OAuth → зарегистрировать приложение с правами на «Пользовательские данные»
   и API статистики (точный scope — по актуальной документации Яндекса на момент подключения;
   не угадывать).
2. Получить OAuth-токен, добавить в GitHub Secrets репозитория как `WORDSTAT_TOKEN`.
3. Доработать `scripts/fetch-wordstat.mjs` (каркас и схема интеграции описаны в самом файле):
   запрос по списку запросов `market.demand.queries`, регион Новосибирская обл.
4. Результат писать в `market.demand` со `status:"ok"` и полным провенансом; раздел «Спрос»
   на сайте начнёт строиться сам.

## Наследие v1 (предположения проекта — помечены, редактируемые)

Ставка аренды 1 000 ₽/м², цена билета 300–350 ₽, схема 70/30 с ДК, УСН 6% как расчётная,
гонорары 5 000/4 300/6 500/15 500 ₽, полиграфия 10 ₽/зритель, износ 400/600 ₽, переменные
праздника 2 953 ₽, мощность 55 показов/труппа. Всё это `confidence:"model"` в
`data/config.json` + часть в `rates.json`; в интерфейсе калькуляторов — редактируемые
допущения (кнопка «Допущения», override хранится в localStorage и не трогает файлы).
