## Что готово

- **Каркас**: `index.html` + `css/` + ES-модули `js/`. Классический `js/boot.js` отвечает за тему и заставку и работает даже при сбое модулей; сторожевой таймер показывает баннер «приложение не стартовало» с подсказкой.
- **Кнопка «Далее» исправлена.** Причина — SyntaxError (`a && b ?? c`) в `data-loader.js`, из-за него не грузились все модули.
- **Заставка**: «Юлия, приветствую Вас», подзаголовок в 2 строки, векторный логотип по ролику (SVG + CSS), экран выбора режима с мини-макетами, `prefers-reduced-motion`, кнопка «Заставка» в шапке.
- **Дизайн**: монохромная палитра Apple, bento-сетка, светлая/тёмная темы, анимируются только `transform`/`opacity`.
- **9 калькуляторов** — чистые функции; все константы в `data/config.json` и `data/rates.json` с провенансом (`value, unit, source_name, source_url, fetched_at, valid_from, confidence`). Сценарии, сравнение, печать.
- **Навигатор рынка**: карта Leaflet (CartoDB Positron/Dark Matter, `invalidateSize`), режимы «Новосибирск» и «Города области», календарь, сезонность, конкуренты. Нет данных → «подключите источник» и ручной ввод.
- **Справочник**: вкладки с чек-листами, шаблоны, глоссарий, гранты, 30-дневный чек-лист с прогрессом (localStorage).
- **Автоматизация**: `deploy.yml` (Pages через Actions), `data-refresh.yml` (cron + dispatch; при сбое источника — `stale` и бейдж «Данные устарели»). Бот уже сделал коммит с курсами ЦБ — слит в `v2`.
- **Сборка**: `npm run build` → `_site/` (+ офлайн-файл `_site/yulia-offline.html`, открывается двойным кликом).
- **Тесты**: `node --test` — 122/122. Ожидаемые значения не подгонялись под код (расхождения разобраны выводом из формул, обоснования — в комментариях тестов).

## Правила, которые нельзя ломать

- Не подгонять ожидаемые значения тестов под код.
- Числа без источника не вносить: «нет данных» + ручной ввод.
- Правка констант — только в `data/*.json` с провенансом.
- Отложенный CSS помечен `/* @defer */…/* @end-defer */` в `css/components.css`; тяжёлые секции строятся лениво в `js/app.js` (`lazySections`). Новой секции с DOM до прокрутки нужен вызов через `lazySections`.
- Шрифтовые стеки продублированы в `css/base.css` (с подменой «Inter Fallback» и «Playfair Fallback»): менять парно с `tokens.css`.
- Удалять файлы репозитория и сливать в `main` — только с ведома владельца.
