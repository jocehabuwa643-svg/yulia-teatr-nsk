# Бизнес-помощник Юлии

Личный кабинет-инструмент для запуска детского театра в Новосибирске и области: справочник, навигатор рынка,
калькуляторы и карта. Интерфейс на русском. Статический сайт: чистый HTML/CSS/ES-модули, без фреймворков.

## Как открыть

| Способ | Как |
|---|---|
| Сайт на GitHub Pages | https://jocehabuwa643-svg.github.io/yulia-teatr-nsk/ (после слияния ветки в `main`) |
| Офлайн-версия | скачать `yulia-offline.html` с сайта (`…/yulia-offline.html`) и открыть двойным кликом |
| Локально | в папке проекта: `npx serve .` или `python -m http.server 8080`, затем http://localhost:8080/ |

**Почему исходный `index.html` не открывается двойным кликом (`file://`).** Браузеры блокируют ES-модули
(`<script type="module">`) и `fetch()` для файлов с диска: приложение не загрузит ни скрипты, ни `data/*.json`.
Поэтому есть офлайн-версия — один файл, где стили, скрипты и все данные вшиты в страницу.
Карта, графики и иконки подгружаются с CDN; без интернета они показывают плашку, остальное работает.

## Команды

```
npm ci                 # установить зависимости (только esbuild, версия закреплена)
npm test               # юнит-тесты калькуляторов (node --test)
npm run build          # собрать _site/: сайт + yulia-offline.html
npm run build:offline  # пересобрать только офлайн-файл
npm run serve          # локальный сервер (serve@14.2.6)
```

Что делает `npm run build`: копирует `index.html`, `css/`, `data/`, `js/boot.js`, `favicon.svg`, `.nojekyll`
в `_site/`; склеивает `js/app.js` со всеми модулями в `assets/app.js` (esbuild, IIFE, ES2019, minify) и подменяет
подключение в `_site/index.html`; собирает `_site/yulia-offline.html`. Нет esbuild — модули копируются как есть
(офлайн-версия в этом случае пропускается). Ошибка сборки — код 1 и понятное сообщение.

## Структура

```
index.html            страница (секции разделов, заставка)
css/                  tokens → themes → base → components → splash/calc/market/guide
js/boot.js            классический скрипт: тема, заставка, сторожевой таймер
js/app.js             точка входа ES-модулей; разделы запускаются изолированно
js/calculators/       чистые формулы (без DOM), покрыты тестами
js/ui/                помощники интерфейса и отрисовка калькуляторов
data/*.json           все цифры и источники (провенанс)
data/archive.html     архив исследования (фрагмент HTML)
scripts/              build.mjs, fetch-cbr.mjs, fetch-wordstat.mjs, fetch-util.mjs, touch-meta.mjs
tests/                тесты (node --test)
archive/              прежняя версия (index.old.html)
.github/workflows/    deploy.yml, data-refresh.yml
```

Подробности: [ARCHITECTURE.md](ARCHITECTURE.md).

## Данные и их обновление

Ни одной цифры в коде: ставки, пороги, цены, курсы лежат в `data/*.json`. У каждого значения есть провенанс:

| Поле | Смысл |
|---|---|
| `value`, `unit` | значение и единица |
| `source_name`, `source_url` | откуда взято |
| `fetched_at`, `valid_from` | когда получено и с какой даты действует |
| `confidence` | `high` (официальный документ), `medium`, `model` (предположение проекта), `low`, `no_data` |
| `stale`, `stale_since` | источник не ответил: значение прежнее, помечено устаревшим |

Нет проверенного значения — `value: null`, `status: "no_data"`; в интерфейсе остаётся ручной ввод.
Предположения проекта (аренда 1 000 ₽/м², билет 300–350 ₽, схема 70/30 для ДК, ИП на УСН 6%) помечены
и редактируются в интерфейсе.

Автообновление (`data-refresh.yml`, ежедневно 03:17 UTC и вручную): курсы ЦБ РФ (`fetch-cbr.mjs`), спрос
Wordstat (`fetch-wordstat.mjs`, только при секрете). Сбой источника не роняет задачу и не затирает данные.
Коммит делается, только если `data/` изменилась, после чего запускается пересборка сайта.
Налоговые пороги, цены и прочее обновляются вручную: правка `data/*.json` с актуальными `source_url` и `fetched_at`.

## Публикация на GitHub Pages

1. Settings → Pages → Source: **GitHub Actions**.
2. Слить ветку в `main`: `deploy.yml` соберёт `_site/` и опубликует. Для pull request выполняются только тесты и сборка.

## Секрет Wordstat

Settings → Secrets and variables → Actions: секрет `WORDSTAT_TOKEN` (ключ API) и переменная `WORDSTAT_FOLDER_ID`.
Без секрета шаг пропускается. Формат запроса адаптера сверен по стороннему разбору API, а не по официальной
спецификации: при первом запуске проверьте лог; при расхождении данные не затираются.
Шаблон переменных: `.env.example`.

## Откат на старую версию

Прежняя версия сохранена тегом `old-v1` и файлом `archive/index.old.html`:
`git checkout old-v1` (просмотр) или `git revert` слияния v2 в `main`.
